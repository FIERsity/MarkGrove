# MarkGrove 结构化写作 v0.4 Spec

## 1. 产品原则

MarkGrove v0.4 把“接近阅读的直接编辑”和“像积木一样整理段落”合并为同一条工作流。目标不是复制 Notion 的专有文档格式，而是在不牺牲标准 Markdown、离线能力和数据归属的前提下，降低写作与整理的动作成本。

长期原则：

1. 打开即阅读，点击即编辑；默认不要求在预览与源码之间来回切换。
2. 文本、指针和键盘操作等价；高频动作离光标近，低频动作收进菜单。
3. Markdown 始终是唯一事实来源；Block、拖动状态和大纲都是即时派生视图。
4. 一次用户意图对应一次 CodeMirror transaction，可正常撤销和重做。
5. 无法无损判断的结构宁可保留源码，不静默改写内容。

## 2. Markdown 方言与渲染契约

支持 CommonMark、GFM 与数学扩展：

- `$...$`：行内 LaTeX。定界符不能跨行，紧邻空白、未闭合、已转义或位于代码中的美元符号保持源码。
- 独占行的 `$$`、公式正文、独占行的 `$$`：块级 LaTeX。未闭合结构保持源码。
- `---`、`***` 等符合 CommonMark 的 Horizontal Rule 才显示分隔线。
- H1–H6 只通过字号、字重和留白建立层级；H2 不自动附加装饰线。
- 原始 HTML 不执行，远程 Markdown 图片不请求，危险协议链接不打开。

Live Preview 的公式由本地 KaTeX 渲染；点击公式会回到对应源码区间。阅读与分栏视图使用 `remark-math → rehype-katex`。两条链路均设置 `trust: false`、大小与展开上限，不使用 CDN、远程宏或运行时服务。无效公式显示可编辑的安全回退，不阻塞整篇笔记。

## 3. Block 模型

Block 不是持久化记录，而是 Lezer 语法树中的可移动结构：

- 文档级：段落、标题、引用、代码块、块公式、表格、分隔线和 HTML 源码块。
- 列表级：每个 ListItem 是一个 Block；移动父列表项时携带它的嵌套列表。
- 代码块、表格、引用和块公式按原子结构移动，不在拖动过程中拆开。
- 指针拖动按兄弟块的屏幕盒子和块间空隙命中，不再依赖空白行上的 `posAtCoords`。
- 段落和标题拖进列表会变成列表项；列表项拖到文档级会拆回普通段落，拖到另一列表则加入该列表。
- 代码块、表格、引用、公式、分隔线和 HTML 不能变成列表项；停在列表内部时显示禁止，不静默失败。
- 键盘、菜单仍只做同一父级重排。横向缩进/取消缩进、多选拖动、Alt 复制不在本版本。

系统不向 Markdown 写入 block ID、注释标记或隐藏元数据，因此导出文件可由任意标准 Markdown 工具继续编辑，旧笔记、修订和 ZIP 备份无需迁移。

## 4. 就地操作

可见 Block 左侧提供低干扰控制：

- `+`：在当前 Block 下方创建空段落并把光标放入新位置。
- 六点手柄：点击打开操作菜单，拖动按当前指针下的空隙或列表槽位放置。
- 菜单：上移、下移、复制、删除，以及转换为正文、H1/H2/H3、项目列表、编号列表、任务、引用、代码或公式。
- `⌘/Ctrl Shift ↑/↓`：移动当前 Block；当选区覆盖多个连续同级 Block 时，整体移动选区。

有序列表移动时保留“位置上的编号标记”，避免把原项目编号带到新首项；所有移动保留项目正文、嵌套子项和相邻 Markdown 分隔空白。拖动在目标空隙显示整宽插入条；变成列表项、移出列表或加入另一列表时附带文字说明。非法目标显示“无法放在这里”，并把光标改为禁止。接近编辑区上下边缘时自动滚动。

## 5. 输入流

### 5.1 斜杠菜单

在空白段落行首输入 `/` 打开本地命令菜单。输入中英文关键词可筛选，方向键选择，Enter 应用，Escape 关闭。可插入正文、H1/H2/H3、项目列表、编号列表、任务、引用、代码块、块公式和分隔线。命令只替换当前 `/关键词`，并把光标放到模板最有用的编辑位置。

### 5.2 Enter 语义

- Live Preview 普通段落和标题中的 Enter 创建新的 Markdown 段落。
- 列表、任务、引用和代码沿用 CodeMirror/Markdown 的原生续写与退出规则。
- Shift Enter 写入 Markdown 硬换行 `\\\n`。
- 源码模式保持字面编辑，不加入 Live Preview 的段落语义。
- 输入法 composition 期间不执行结构命令、模板替换或拖动写入。

## 6. 本文大纲

大纲从 H1–H6 即时派生，并按标题层级缩进；空标题不产生持久化占位。点击标题时：

- Live Preview/源码：移动 CodeMirror selection 到标题源码并滚入视口。
- 阅读视图：滚动到携带源偏移的渲染标题。

大纲开关存入本地 settings；标题条目和展开状态不进入笔记正文或备份协议。分栏模式为保留编辑宽度暂不同时打开右侧大纲。

## 7. 人体工学与可访问性

- 控制仅在悬停、当前 Block 或键盘焦点附近增强显示，不持续占用正文宽度。
- 菜单和斜杠命令公开语义角色、中文/英文名称和当前选择；大纲使用独立导航区域。
- 指针重排均有菜单和快捷键等价入口；拖动不是唯一操作方式。
- 公式输出包含 KaTeX 的 HTML 与 MathML；视觉 MathML 由本地样式正确隐藏，辅助技术仍可读取。
- `prefers-reduced-motion` 下关闭平滑动画；窄屏保持正文可操作，并隐藏会挤压正文的辅助大纲。

## 8. 数据、安全与性能

- 本版本不改变 Dexie v3 schema、笔记记录、修订记录、单篇 Markdown 或 ZIP v2 格式。
- 正文变更继续通过既有 650ms 防抖与同笔记串行保存队列写入 IndexedDB。
- Block 图只基于当前 CodeMirror state 构建；可见控制只为视口附近结构生成。
- 核心依赖与 KaTeX 字体进入 PWA app-shell 预缓存；离线时不发起正文、公式或图片网络请求。
- 不新增账号、同步、协作、附件、遥测、分析或 AI。

## 9. 验收标准

1. 行内/块公式在 Live Preview 和阅读视图语义一致；价格、代码、转义和未闭合定界符不被误判。
2. H2 没有自动下划线；Horizontal Rule 在非活动状态显示为线，进入后可编辑源码。
3. 段落、标题、引用、代码、公式、表格和列表项均可通过菜单重排；嵌套列表随父项移动。
4. 指针可把段落/标题放进列表、把最后一项移出后让空列表消失，或把一项加入另一列表；代码块停在列表内部时被拒绝。
5. 多 Block 选区整体移动，有序列表编号稳定；每次操作一次撤销即可恢复。
6. `/` 菜单可筛选并正确放置光标；普通正文中的 `/` 不触发菜单。
7. 大纲实时更新，并在编辑与阅读视图正确定位；不修改 Markdown 内容。
8. 中文 IME composition 不重复提交或触发结构操作。
9. 刷新与离线重开后正文、视图和大纲开关保持；无远程公式、图片或正文请求。
10. `npm run check`、约 `1440×900` Chromium 交互验收与控制台检查通过。
