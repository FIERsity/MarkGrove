# MarkGrove Workspace v0.2 Spec

## 1. 产品意图

MarkGrove 是一个先写再整理、整理时不打断思路的本地 Markdown 工作台。v0.2 的核心不是增加一套“文件管理器”，而是让空间结构成为写作的低摩擦延伸。

三个判断原则：

1. **就近完成**：新建、命名、移动和撤销尽量留在当前视线与键盘位置。
2. **渐进整理**：Inbox 永远可直接写；文件夹、标签和收藏都是可选组织方式。
3. **动作可解释、可恢复**：拖动目标必须可见，结构变化进入当前会话撤销历史，永久删除单独确认。

## 2. 信息架构

左侧栏从上到下分为：

- 全局入口：Inbox、最近、收藏、全部笔记。
- 资料树：文件夹与笔记混排，允许任意层级文件夹。
- 标签：从现有笔记实时派生。
- 回收站：展示直接删除的笔记和最高层级的已删除文件夹。

主区域只承载两种上下文：一篇打开的笔记，或当前导航入口的内容概览。面包屑明确显示当前文件夹路径，并可逐级返回。

`⌘/Ctrl K` 是跨层级快速入口。无搜索词时按最近打开时间列出笔记；输入后同时检索标题、正文、标签、文件夹名称和路径。

## 3. 数据模型与排序

- `FolderRecord`：`id`、`parentId`、`name`、`orderKey`、创建/更新时间和删除时间。
- `NoteRecord` 新增：`parentId`、`orderKey`、`lastOpenedAt`。
- 根目录使用保留 ID `root`，不创建伪文件夹记录。
- 文件夹和笔记共享同一兄弟序列，按固定宽度稀疏十进制 `orderKey` 排序；只有相邻键无空间时才局部重排。
- 移动在单个 IndexedDB 事务内完成。文件夹目标必须存在且未删除，并禁止移动到自身或任一后代。

Dexie schema v3 将 v1/v2 笔记稳定迁移到根目录：置顶优先，其后按更新时间倒序及 ID 排序。正文、标签、frontmatter、修订和删除状态不改写。

## 4. 结构操作

### 新建

- 在 Inbox 或根级入口新建笔记：放到根目录末尾。
- 在文件夹中新建笔记或子文件夹：放到该文件夹末尾。
- 在标签入口新建笔记：自动带上该标签。
- 新建笔记后标题获得焦点，用户可以直接命名。

### 拖动

- 指针移动阈值为 6 px，避免点击时误拖。
- 每个目标提供“之前 / 内部 / 之后”三个明确落点；笔记只提供前后，文件夹额外提供内部。
- 悬停折叠文件夹 650 ms 后自动展开。
- 拖到可滚动边缘时自动滚动；拖动中使用浮层显示被移动项。
- 拖动手柄常驻于键盘可达结构中，视觉上在悬停或聚焦时增强，不依赖像素级精细操作。

### 键盘与无拖动替代

- 树中使用方向键、Home、End 浏览；右键展开，左键折叠或返回父级；Enter 打开；F2 重命名。
- Space 进入键盘移动模式；上下改变相邻位置，左右改变层级，Enter 提交，Escape 取消。
- “移动到…”对话框可搜索目标文件夹，并选择放在末尾、某项之前或之后。它与拖动调用相同存储命令，保证结果一致。

### 删除、解散与撤销

- 删除文件夹只给文件夹本身写入删除时间；后代通过祖先状态被视为已删除，恢复时结构完整返回。
- 解散文件夹会删除容器并把直接子项原位提升一级；撤销会恢复文件夹及子项的原始位置键。
- 当前会话最多保留 20 个结构撤销动作。非文本输入焦点下，`⌘/Ctrl Z` 撤销最近结构操作。
- 永久删除文件夹前显示其后代文件夹与笔记数量，并要求输入文件夹名；删除笔记时级联清理修订。

## 5. 人体工学与可访问性

- 桌面默认侧栏宽 304 px，可在 240–420 px 间拖动或用键盘调节并持久保存；`⌘/Ctrl \\` 折叠。
- 树行高 36 px，精细控件不小于 24 px；粗指针环境行高和按钮目标提高到 44 px。
- 打开对话框后焦点进入首个输入框；Tab 保持在对话框内；Escape 关闭；关闭后焦点回到触发控件。
- 拖动和键盘移动都向屏幕阅读器播报被移动项、目标与完成/取消状态。
- 选中、焦点和拖放目标不只依靠颜色表达；减少动态效果设置下关闭非必要过渡。
- 侧栏变化不压缩编辑器到不可写状态；小视口下侧栏变为覆盖层，既有响应式能力保持可用。

## 6. 备份、隐私与故障边界

- 所有结构数据留在 IndexedDB；Service Worker 只缓存应用外壳。
- v2 ZIP manifest 保存文件夹、笔记归属、顺序和最近打开时间；Markdown 正文仍是可单独读取的标准文件。
- 恢复器显式读取 v1 和 v2。v1 笔记按稳定顺序进入根目录。
- 冲突 ID 不覆盖现有数据：冲突文件夹整体重映射，其后代跟随新 ID；冲突笔记改 ID并标记为 imported。
- 导入根目录的内容作为一个有序块追加在现有内容之后。
- manifest 路径穿越、重复 ID/路径、缺失父级、文件夹环和大小/数量超限必须在写入前拒绝。

## 7. v0.2 验收标准

1. 老 v1/v2 数据原地升级后，笔记正文和已有修订不变。
2. 文件夹和笔记可通过指针、键盘和移动对话框得到等价的前后/内部位置。
3. 文件夹不能移入自身或后代；失败不产生半完成状态。
4. 删除与恢复父文件夹时，完整后代结构随之隐藏和返回。
5. 移动与解散可在当前会话撤销；编辑器内的常规文本撤销不被拦截。
6. v2 备份可恢复层级与顺序；真实 v1 fixture 仍能导入。
7. 快速打开可找到正文命中和深层文件夹，且全程可用键盘完成。
8. `npm run check` 通过，并在约 1440×900 的 Chromium 中完成刷新持久化、拖动、键盘移动、回收站、备份恢复、离线重载和控制台检查。
