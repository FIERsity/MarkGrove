# MarkGrove Live Preview v0.3 Spec

## 1. 目标

笔记默认以接近阅读视图的排版打开，但始终可以直接点击并编辑。Markdown 源码仍是唯一事实来源，不引入 HTML 到 Markdown 的往返转换。

体验原则：

1. 打开即阅读，点击即写作。
2. 光标只让当前格式的必要语法显露，不让整篇笔记突然变成源码。
3. 实时预览与源码共用光标、选区和撤销历史。
4. 无法安全、无损地实时渲染的结构保留清晰源码，不猜测用户意图。

## 2. 模式

- `live`：默认，可编辑；隐藏非活动 Markdown 定界符并显示阅读排版。
- `source`：可编辑；显示完整 Markdown、行号和等宽字体。
- `reading`：只读；使用安全 GFM 渲染器进行最终校对。
- `split`：次级入口；左侧源码，右侧阅读渲染。

`⌘/Ctrl E` 在阅读视图与上一次编辑模式之间切换。切换模式不卸载 CodeMirror；切换笔记则按笔记 ID 创建新编辑状态，避免撤销历史跨笔记传播。

旧设置迁移：edit → source，split → live，preview → live。新模式写入 `editorViewMode`，不改变 Dexie schema 或任何笔记记录。

## 3. 渲染规则

- 标题：隐藏非活动 `#`，保留 H1–H6 字号；进入标题时显露标记。
- 强调：粗体、斜体、删除线保留排版；点击内容后显露对应定界符。
- 行内代码：以等宽背景呈现；进入后显露反引号。
- 链接：默认只显示标题；普通点击进入源码，`⌘/Ctrl + 点击`验证协议后打开。
- 列表：非活动项目符号显示为统一圆点；有序编号保留；当前列表项显露原标记。
- 任务：复选框直接把 `[ ]` 与 `[x]` 互换；`⌘/Ctrl Enter`提供键盘等价操作。
- 引用：使用左侧强调线，当前行显露 `>`。
- fenced code：代码正文保持等宽块，非活动围栏弱化/隐藏；复杂内容仍可切源码精确编辑。
- 图片：远程地址永不请求；非活动时显示隐私占位，点击后显露完整 Markdown。
- 表格：v0.3 以整理过的 GFM 源码呈现；阅读模式显示完整表格。
- HTML：永不执行，实时预览保持可辨认源码，阅读模式跳过。

## 4. 技术结构

CodeMirror 文档是唯一编辑状态。Lezer GFM 语法树生成两类装饰：

- 直接状态字段维护标题、引用、代码和表格等行级装饰。
- 视口插件维护强调、链接、定界符、任务和图片等行内装饰，并在文档、选区、焦点、语法树或视口变化时增量重建。

隐藏定界符使用 replace decoration 与 atomic ranges。格式片段携带原始源码区间；点击后通过浏览器 caret 位置映射回 CodeMirror 文档并提交 selection transaction，随后重新显示语法。

Live Preview、源码编辑和自动保存继续走同一条 `docChanged → draft → 650ms 串行写入` 链。阅读模式复用既有 ReactMarkdown 安全渲染器；链接协议判断抽为共享策略。

## 5. 安全与可访问性

- 不加载远程图片，不执行 HTML，不开放 javascript/data 协议。
- 任务控件提供 checkbox 角色、状态和中英文标签。
- 模式按钮公开 pressed 状态；编辑器按模式提供明确 aria label。
- 实时预览始终保留源码模式作为键盘、屏幕阅读器和复杂格式的确定性出口。
- 中文输入法 composition 期间不替换当前活动内容。

## 6. 验收标准

1. 默认模式为 Live Preview；旧设置按规则迁移且内容不变。
2. 点击标题、强调、链接、代码和图片时光标落到正确源码位置。
3. 模式切换保留光标和撤销链；换笔记后撤销不影响上一笔记。
4. 中文 IME composition 只提交一次，不闪烁或重复。
5. 任务点击和快捷键只修改对应三个字符。
6. 普通链接点击不导航，修饰键点击只打开允许协议。
7. 阅读与 Live Preview 对常用 GFM 内容语义一致；复杂表格可随时进入源码。
8. 刷新后内容与模式持久保存；离线生产构建可以启动。
9. `npm run check` 与约 1440×900 Chromium 验收通过，控制台无错误和警告。
